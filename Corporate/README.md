# Shikhar Group

Corporate website for Shikhar Group Pvt. Ltd., a Kathmandu-based enterprise working in infrastructure, energy, digital services, and agribusiness. The site presents the group’s services, projects, insights, and careers as a static front end.

The interface is built with React, React Router, Tailwind CSS, and Framer Motion. Copy, navigation, and page content are maintained in `src/data/site.js`. The project does not use a server or database.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The build writes the deployable site to `dist/`.
